# Веб-приложение

Интерфейс находится в `web-server/` (React + Vite), API — в `server/`
(FastAPI), пользователи и подписки — в `storage/web.db`, результаты —
в `database.db`. Парсер читает подписки независимо от процесса API.

## Подписки

Создание и изменение через `/api/links` проверяют HTTP(S)-адрес на домене
`avito.ru` или его поддомене, неотрицательные цены и порядок границ,
дату в формате `YYYY-MM-DD`. Ключевые слова очищаются от пробелов и дублей.

## Сессии

`POST /api/login` и `POST /api/register` возвращают bearer-токен.
`GET /api/me` возвращает текущего пользователя и признак администратора.
`POST /api/logout` отзывает только переданный токен; повторный выход безопасен.

Каждый вход создаёт отдельную сессию на 30 дней. Сессии пользователей
и администратора хранятся в SQLite и доступны всем процессам API.
В базе сохраняются только хеши токенов. Изменение пароля администратора
в конфигурации и перезапуск API делают его прежние сессии недействительными.

При первом запуске старые пользовательские токены автоматически переносятся
в таблицу сессий на 30 дней и удаляются из `users.token`. Старые сессии
администратора, существовавшие только в памяти, требуют повторного входа.
