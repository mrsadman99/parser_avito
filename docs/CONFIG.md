# Конфигурация Avito Parser

Файл конфигурации: **`config.toml`** в корне проекта.

- Загружается модулем `load_config.py` (`tomllib`) и валидируется моделью `AvitoConfig` (`dto.py`).
- Все настройки лежат в секции `[avito]`.
- Вносить настройки можно двумя способами (они пишут в один файл):
  1. **GUI** (`python AvitoParser.py`) — форма Flet: загружает `config.toml` при старте и сохраняет обратно при нажатии кнопок.
  2. **Вручную** — редактирование `config.toml` текстом (нужно для CLI/сервера/Docker).
- Некоторые параметры есть в модели `AvitoConfig`, но **не выведены** в `config.toml`/GUI (используются значения по умолчанию) — они отмечены в тексте.

> ⚠️ Формат TOML: строки в `"..."`, массивы в `[...]` (без висячей запятой после последнего элемента), булевы значения — `true`/`false`, комментарии — `#`.

## 📌 Ссылки и объёмы

### `urls` — массив строк

Ссылки на поиск/категории Avito для мониторинга. Каждая ссылка преобразуется в мобильный API-адрес (через сервис SPFA) и проверяется отдельно.

```toml
urls = [
    "https://www.avito.ru/novosibirsk/nastolnye_kompyutery/sistemnye_bloki-ASgBAgICAUS02xKMqY0D?q=%D0%B8%D0%B3%D1%80%D0%BE%D0%B2%D0%BE%D0%B9+%D0%BF%D0%BA"
]
```

**Поиск по ключевому слову** задаётся самой ссылкой (параметр `?q=...` в URL Avito).
**Обязательный параметр** — без ссылок парсеру нечего отслеживать.

### `count` — целое число

Сколько страниц (по ~50 объявлений) брать за проход по каждой ссылке.

```toml
count = 1   # только первая страница
```

`1` — одна страница, `2` — две и т.д. В GUI-режиме ограничение — до 100 ссылок; в CLI ограничений нет.

## 🎯 Фильтры

### `keys_word_white_list` — массив строк

**Белый список**: оставить только те объявления, где хотя бы одна из фраз встречается в **заголовке или описании** (проверка регистронезависимая).

```toml
keys_word_white_list = ["игровой", "rtx"]
```

Пусто = без фильтра.

### `keys_word_black_list` — массив строк

**Чёрный список**: исключить объявления, где встречается любая из фраз (по заголовку/описанию).

```toml
keys_word_black_list = ["сломан", "не работает"]
```

### `seller_black_list` — массив строк

Чёрный список продавцов (по `sellerId`). Объявления этих продавцов пропускаются.

```toml
seller_black_list = ["sales-user-12345"]
```

### `min_price` / `max_price` — целые числа

Границы цены (единые для **всех** объявлений и **всех** ссылок). `ad.priceDetailed.value` должен попасть в диапазон.

```toml
min_price = 0
max_price = 30000
```

По умолчанию: `min_price = 0`, `max_price = 99999999` (без ограничения).

### `geo` — строка

Фильтр по адресу/региону: оставить объявления, в `formattedAddress` которых встречается эта строка.

```toml
geo = "Новосибирск"
```

Пусто = без фильтра.

### `max_age` — целое число (секунды)

Максимальный «возраст» объявления от момента публикации (`sortTimeStamp`).

```toml
max_age = 0       # без ограничения
max_age = 86400   # только за последние 24 часа
```

### `ignore_reserv` — булево

`true` — пропускать объявления со статусом **«Зарезервировано»** (`isReserved`). По умолчанию `true`.

### `ignore_promotion` — булево

`true` — пропускать **продвигаемые** объявления (с пометкой «Продвинуто» в `iva`). По умолчанию `false`.

> Порядок применения фильтров (`filters/ads_filter.py`): уже просмотренные → цена → чёрный список ключевых слов → белый список → geo → продавцы → возраст → «Зарезервировано» → «Продвинуто».

## ⏱ Паузы и повторы

### `pause_general` — целое число (секунды)

Пауза **между полными проходами** по всем ссылкам (в GUI — между нажатиями цикла).

```toml
pause_general = 300   # 5 минут между проходами
```

### `pause_between_links` — целое число (секунды)

Пауза между проверкой разных ссылок и между страницами одной ссылки.

### `max_count_of_retry` — целое число

Максимум повторных попыток запроса при ошибке.

```toml
max_count_of_retry = 5
```

### `retry_delay` — целое число (секунды)

Пауза между повторными попытками при ошибке запроса.

### `timeout` — целое число (секунды)

Таймаут HTTP-запроса.

```toml
timeout = 30
```

### `block_threshold` — целое число

Сколько блокировок (403/429/439) подряд нужно, чтобы запустить «обработку бана»: смена IP (если мобильный прокси) + обновление/покупка cookies (SPFA).

```toml
block_threshold = 3
```

### `retry_on_failure` — булево

**Быстрый повтор при неудачном проходе.** Если проход завершился неудачей (все запросы упали/заблокированы — `good_request_count == 0`, есть ошибки), парсер **не ждёт `pause_general`**, а повторяет обход раньше — через `retry_on_failure_delay`.

```toml
retry_on_failure = true
```

Работает и в CLI (`python parser_cls.py`), и в GUI. При успешном проходе пауза остаётся `pause_general`.

### `retry_on_failure_delay` — целое число (секунды)

Пауза перед повторным запуском, если проход не удался (вместо `pause_general`). Нужна, чтобы не «долбить» Avito без остановки при блокировках.

```toml
retry_on_failure_delay = 30
```

## 🛡 Прокси и обход блокировок

### `proxy_string` — строка

Прокси для запросов к Avito в формате `username:password@host:port`.

```toml
proxy_string = ""   # без прокси
```

- **+ `proxy_change_url`** → мобильный прокси (умеет менять IP)
- **без `proxy_change_url`** → серверный (статический) прокси
- Только **HTTP(S)** — SOCKS не поддерживается без правки кода.

### `proxy_change_url` — строка

URL для смены IP (только для мобильных прокси), например `https://changeip.mobileproxy.space/?proxy_key=***`.
Парсер дёргает этот URL при блокировках (`+&format=json`) и получает новый IP.
Пусто = IP не меняется.

### `use_webdriver` — булево

Использовать WebDriver/Playwright (для получения собственных cookies через `get_cookies.py`).

### `use_bypass_api` — булево

`true` — использовать сторонний сервис cookies **SPFA (spfa.ru)**: покупка и разблокировка cookies при блокировках.

```toml
use_bypass_api = false
```

### `cookies_api_key` — строка

API-ключ сервиса SPFA. Нужен при `use_bypass_api = true` (и для парсинга телефонов).

```toml
cookies_api_key = ""
```

### `use_own_cookies` — булево

`true` — использовать свои cookies из `storage/own_cookies.json` (получаются скриптом `get_cookies.py`).
⚠️ **Взаимоисключает** `use_bypass_api` (фабрика выберет один провайдер).

### `purchase_cooldown` — целое число (секунды)

Минимальный интервал между повторными покупками cookies через SPFA (защита баланса).
В `config.toml` по умолчанию не выведен — дефолт `600` (10 минут).

### `parse_phone` — булево

Парсить телефон продавца (через SPFA `/api/phone/`).

```toml
parse_phone = true
```

> ⚠️ **Внимание:** в текущей версии кода метод `parse_phone()` — заглушка (всегда возвращает объявления без телефонов). Параметр технически есть, но функция ещё не активна.

## 🔔 Уведомления

### `tg_token` — строка

Токен Telegram-бота (от [@BotFather](https://t.me/BotFather)).

```toml
tg_token = "8902614727:AAGGBcst2BSV0Hmlm6Mlez2usyaHC0L9a5g"
```

Пусто = без Telegram-уведомлений.

### `tg_chat_id` — массив строк

Получатели в Telegram (`chat_id`, можно несколько).

```toml
tg_chat_id = ["389175229"]
```

ID можно узнать через [@userinfobot](https://t.me/userinfobot) или `/getUpdates`.

### `vk_token` — строка

Ключ API сообщества VK (право на отправку сообщений от имени сообщества + доступ к фото).
Пусто = без VK.

### `vk_user_id` — массив строк

ID получателей в VK (числовой, не username). Можно несколько.

### `proxy_notifier` — строка

**Отдельный прокси только для отправки уведомлений в Telegram** (не связан с `proxy_string`).
Формат: `username:password@host:port` (схема `http://` подставляется кодом).

```toml
proxy_notifier = "127.0.0.1:5222"
```

Нужен, если `api.telegram.org` недоступен напрямую. Применяется только к TG (VK — без прокси).

### `tg_only_text` — булево

`true` — отправлять в Telegram только текст без изображений (`sendMessage` вместо `sendPhoto`).

```toml
tg_only_text = false
```

## 💾 Сохранение и режим работы

### `save_xlsx` — булево

`true` — сохранять результаты в Excel. По умолчанию `true`.
Файлы: `result/avito.xlsx` (один на всё) или `result/avito_link_N_<дата>.xlsx` (при `one_file_for_link`).

### `one_time_start` — булево

`true` — однократный проход и завершение; `false` — бесконечный цикл мониторинга.

```toml
one_time_start = false
```

### `one_file_for_link` — булево

`true` — отдельный Excel-файл для каждой ссылки; `false` — всё в один файл.

### `parse_views` — булево

`true` — дополнительно открывать страницу каждого объявления и парсить просмотры (всего/за сегодня).
⚠️ Доп. запросы → выше нагрузка и риск бана.

```toml
parse_views = false
```

### `output_dir` — строка (путь)

Папка для результатов Excel. В `config.toml`/GUI **не выведен** — дефолт `result`.

### `debug_mode` — целое число

Режим отладки. В `config.toml`/GUI **не выведен** — дефолт `0`.

## 🤖 DeepSeek — оценка цена/производительность

Модуль `parser/ai/deepseek.py`. Оценивает объявления по заголовку и **полному описанию**, сортирует по убыванию оценки «цена/производительность», опираясь на историю предыдущих оценок (`storage/ai_history.json`).

### `use_deepseek` — булево

Включить оценку через DeepSeek. Требуется API-ключ.

```toml
use_deepseek = false
```

При `true` парсер автоматически:

1. Открывает страницу каждого объявления и подтягивает **полное описание** (в API каталога оно обрезано ~250 символов)
2. Оценивает объявления через DeepSeek (пакетами)
3. Сортирует по оценке (лучшие сверху) и сохраняет в Excel/уведомления

### `deepseek_api_key` — строка

API-ключ DeepSeek (получить: [platform.deepseek.com](https://platform.deepseek.com)). Платно, но дёшево.

```toml
deepseek_api_key = ""
```

### `deepseek_model` — строка

Модель DeepSeek. По умолчанию `deepseek-chat` (можно `deepseek-reasoner`).

```toml
deepseek_model = "deepseek-chat"
```

### `deepseek_max_ads_per_run` — целое число

**Сколько объявлений всего** оценивается за один проход парсера (лимит расхода API). По умолчанию `30`.
Остальные объявления прохода получают оценку `0` (отсеиваются при `min_deepseek_score > 0`).

### `deepseek_batch_size` — целое число

**Сколько объявлений отправляется в одном запросе** к DeepSeek. По умолчанию `5`.
Число API-вызовов ≈ `deepseek_max_ads_per_run / deepseek_batch_size`. Больше значение — дешевле, но при очень длинных описаниях точность сопоставления может падать.

### `deepseek_history_size` — целое число

**Сколько лучших ранее оценённых объявлений** подмешивается в промпт как эталон для калибровки шкалы (из `storage/ai_history.json`). По умолчанию `10`.
Обеспечивает сопоставимость оценок между запусками.

### `min_deepseek_score` — целое число (0–100)

**Порог отсечения**: объявления с оценкой ниже этого значения отбрасываются. По умолчанию `0` (оставляем все, но сортируем).

```toml
min_deepseek_score = 0
```

Пример: `60` — оставить только «хорошие покупки».

### `parse_full_description` — булево

Открывать страницу каждого объявления для получения **полного описания** (в выдаче API оно обрезано ~250 символов).
Автоматически включается при `use_deepseek = true`; отдельно полезно, если нужно полное описание в Excel без оценки.

```toml
parse_full_description = false
```

## 📊 Что попадает в Excel

Колонки (`parser/export/excel.py`):

| Колонка                                 | Источник                                                                           |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Название                               | `ad.title`                                                                               |
| Цена                                       | `ad.priceDetailed.value`                                                                 |
| URL                                            | `https://www.avito.ru/{ad.urlPath}`                                                      |
| Описание                               | `ad.description` (полное, если включён парсинг описания) |
| Дата публикации                  | `ad.sortTimeStamp` (локальный часовой пояс)                          |
| Продавец                               | `ad.sellerId`                                                                            |
| Адрес                                     | `ad.location.name`                                                                       |
| Адрес пользователя            | `coords.address_user`                                                                    |
| Координаты                           | `coords.lat;lng`                                                                         |
| Изображения                         | URL самого большого фото                                                 |
| Поднято                                 | «Да»/«Нет» (`isPromotion`)                                                      |
| Просмотры (всего/сегодня) | из`parse_views`                                                                        |
| Телефон                                 | `ad.phone` (из `parse_phone`)                                                        |
| **AI оценка**                      | `ad.ai_score` (из DeepSeek)                                                            |
| **AI причина**                    | `ad.ai_reason` (из DeepSeek)                                                           |

## Минимальный рабочий конфиг

```toml
[avito]
urls = ["https://www.avito.ru/novosibirsk/nastolnye_kompyutery?q=игровой+пк"]
count = 1
max_price = 30000
save_xlsx = true
```

Остальное — по желанию: без токенов TG/VK уведомления не отправятся, без прокси/cookies парсер пойдёт напрямую (выше риск бана, но для теста достаточно).
